# 伴星视觉样片（Claude 版）

**这是视觉样片，不是真实系统。** 纯静态 HTML + CSS，直接双击打开 `index.html` 就能看，不需要启动任何服务，也不连接任何接口。页面里所有店铺、商品、订单号、收件人、电话、金额和库存数字都是示例数据，例如「示例店铺A」「示例商品-红富士」。

做这份样片是为了把 `伴星设计反馈-Claude.md` 里的视觉方案落成能看的页面，供 fox 判断方向。它没有改 `banxing-nemo` 项目里的任何文件。

## 文件

| 文件 | 内容 |
|---|---|
| `index.html` | 工作台：今日任务队列（按截止时间排）、今日概况、异常提醒、快捷入口、AI 条 |
| `orders.html` | 订单管理：平台/自有切换、分页、AI 条、超时与退款提醒、筛选、状态胶囊、订单表。底部可以切换表格的四种状态：有数据、加载中、无结果、出错 |
| `inventory.html` | 库存：批次表加「放了几天」新鲜度列（今天和 1 天是灰色，2 天琥珀，3 天以上红色，都配文字）、损耗记录、包材库存 |
| `order-detail.html` | 订单详情：AI 修改确认卡（字段、原值、新值对照）、商品、订单进度、收件信息、操作 |
| `styles.css` | 四页共用的一套样式变量和组件 |

侧栏里没有链接的菜单（商品管理、售后等）是样片没做的页面，鼠标停上去会提示「样片未包含此页」。

## 落实了哪些视觉规则

- 主色 `#5B5BF6` 只用在两个地方：当前所在位置（侧栏选中项、一级切换、分页下划线、页码）和主操作按钮（每页一个）。AI 框是唯一用主色描边的组件：1.5px 单色边，外面一圈 `#EEEEFF`。
- 其余全部是中性色。筛选胶囊的选中态用深石墨色，不用主色。状态色只表示状态，而且一律「颜色 + 文字」。
- 没有渐变，没有 `backdrop-filter`，悬停没有 `scale`，没有鼠标光斑，没有跑马灯。顶栏是静态的「今天要办」，最多显示 3 条，后面跟「还有 3 条」可以展开。
- 字号：正文 16px，表格 15px，表头和标签 14px，最小 13px，页标题 24px，区块标题 18px。没有 `zoom`。
- 对比度：次要字 `#596072`，在白底上约 6.3:1。状态文字都加深过，在各自的浅色底上不低于 4.5:1。
- 白底卡片，1px 细边框，不加阴影。
- 字体只用系统中文字体栈：PingFang SC、Hiragino Sans GB、Microsoft YaHei，最后回退到 sans-serif。数字用等宽数字（tabular-nums）。
- 键盘焦点都有可见的描边。系统开了「减少动态效果」时，所有动画都关掉。宽度在 960px 以下时，侧栏收成「菜单」按钮。

## 和反馈文档不一样的地方

反馈文档里写的徽标数字、头像、品牌方块和「详情」文字按钮用主色。这次的要求是主色只用在两个地方，所以这几处都改成了中性色。
